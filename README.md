# Sharpe & Jones — website

Official site for Sharpe & Jones: Elvin Sharpe (vocals) and Morris Jones (production).

Live at https://ginlup77-source.github.io/sharpe-jones/

## Updating the site

- Edit `index.html`. Images live in `img/`.
- Voting link for P4 Nästa Stjärna: set `VOTE_URL` in the script at the bottom of `index.html`.
- Anything committed to the `main` branch goes live automatically within a minute or two.
